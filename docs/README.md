# LLM Engineering Guide

This guide is a companion to the [course README](../README.md). It explains the main ideas of each part, why they matter, and how they fit together, so a reader can move from theory to building real applications.

## How the course is organized

| Part | Focus | Question it answers |
|------|-------|---------------------|
| [1. Fundamentals](01-fundamentals.md) | Math, Python, neural networks, NLP | What do I need to know before working with language models? |
| [2. The LLM Scientist](02-scientist.md) | Architecture, training, alignment, evaluation, compression | How are the best language models built and improved? |
| [3. The LLM Engineer](03-engineer.md) | Inference, retrieval, agents, deployment, security | How do I turn a model into a reliable product? |

The parts build on each other. Part 1 is optional for readers who already know the basics, but Parts 2 and 3 assume that knowledge.

## A simple learning path

1. Learn enough linear algebra, probability, and Python to read model code.
2. Build a small neural network and understand training with gradient descent.
3. Study the transformer architecture and run a pre-trained model locally.
4. Practice fine-tuning and evaluation on a small dataset.
5. Build a retrieval-augmented application and deploy it behind an API.
