# Contributing

Thanks for helping improve this course! Small, focused contributions are the easiest to review.

## Ways to help

- Fix a broken link or a typo.
- Add a resource that is well known and freely available.
- Improve a description so it is clear and short.

## Before you open a pull request

1. Keep each pull request to one topic.
2. Follow the existing format: a title, a short description, and a link.
3. Run the link check locally:

   ```bash
   python3 scripts/check_links.py
   ```

4. Make sure the continuous integration (CI) check passes.

## Style

- Use plain, simple English.
- Keep descriptions under about 15 words.
- Use the emoji and section structure already in the README.
